🔁 Functions & Their Graphs

A function is a rule that assigns exactly one output to every input. Functions are the language of calculus — understanding them deeply is the most important preparation you can do.

Key Concept

A relation is a function if every x-value maps to exactly one y-value. Use the vertical line test: if any vertical line crosses the graph more than once, it is NOT a function.

Function Notation

Instead of writing y = 2x + 1, we write f(x) = 2x + 1. This notation makes it easy to evaluate the function at specific inputs.

  • f(3) means: substitute x = 3 into the formula → f(3) = 2(3) + 1 = 7
  • Domain: all allowed x-values (inputs)
  • Range: all possible y-values (outputs)
✏️ Worked Example 1 — Evaluating a Function
Given f(x) = x² − 3x + 2, find f(4)
Substitute x = 4 everywhere you see x in the formula.
  1. Replace every x with 4:   f(4) = (4)² − 3(4) + 2
  2. Evaluate each term:   16 − 12 + 2
  3. Simplify:   f(4) = 6
f(x) = x² − 3x + 2 f(4) = (4)² − 3(4) + 2 = 16 − 12 + 2 = 6
✏️ Worked Example 2 — Domain Restrictions
Find the domain of f(x) = 1 / (x − 3)
A fraction is undefined when the denominator equals zero. What x makes x − 3 = 0?
  1. Set denominator ≠ 0:   x − 3 ≠ 0
  2. Solve:   x ≠ 3
  3. Domain: all real numbers except x = 3
Denominator: x − 3 ≠ 0 x ≠ 3 Domain: (-∞, 3) ∪ (3, +∞)

📐 Trigonometry Basics

Trigonometry studies relationships between angles and side lengths of triangles. It is the foundation of waves, oscillation, and calculus derivatives of circular motion.

Key Concept — SOH CAH TOA

Sin θ = Opposite / Hypotenuse
Cos θ = Adjacent / Hypotenuse
Tan θ = Opposite / Adjacent

Reference Angles (Unit Circle)

The unit circle (radius = 1) gives exact values for all standard angles. Memorize these three:

Angle sin θ cos θ tan θ
30° (π/6) 1/2 √3/2 1/√3
45° (π/4) √2/2 √2/2 1
60° (π/3) √3/2 1/2 √3
✏️ Worked Example — Right Triangle
In a right triangle, the opposite side = 5, hypotenuse = 13. Find sin θ, cos θ, tan θ.
Use the Pythagorean theorem to find the adjacent side first: a² + 5² = 13²
  1. Find adjacent:   adj² = 13² − 5² = 169 − 25 = 144 → adj = 12
  2. sin θ = opp/hyp = 5/13
  3. cos θ = adj/hyp = 12/13
  4. tan θ = opp/adj = 5/12
adj = √(13² − 5²) = 12 sin θ = 5/13 ≈ 0.385 cos θ = 12/13 ≈ 0.923 tan θ = 5/12 ≈ 0.417

📈 Exponential & Logarithmic Functions

Exponential functions model rapid growth and decay — from compound interest to radioactive decay. Logarithms are their inverses and appear in everything from sound levels to earthquake magnitudes.

Key Concept

y = bˣ is an exponential function (b > 0, b ≠ 1).
log_b(y) = x is its inverse — "log base b of y equals x."
ln x = log_e x is the natural log (base e ≈ 2.718).

Exponent Rules (Review)

  • b^m · b^n = b^(m+n)
  • b^m / b^n = b^(m−n)
  • (b^m)^n = b^(mn)
  • b⁰ = 1   (any nonzero base)
  • b^(−n) = 1/b^n
✏️ Worked Example 1 — Solving an Exponential Equation
Solve: 2ˣ = 32
Write 32 as a power of 2. 32 = 2⁵.
  1. Rewrite 32 as a power of 2:   32 = 2⁵
  2. Set exponents equal:   x = 5
  3. Check:   2⁵ = 32 ✅
2ˣ = 32 = 2⁵ ∴ x = 5
✏️ Worked Example 2 — Solving a Logarithmic Equation
Solve: log₂(x) = 4
Convert from log form to exponential form: log_b(x) = n means b^n = x.
  1. Convert:   log₂(x) = 4 → 2⁴ = x
  2. Evaluate:   x = 16
  3. Check:   log₂(16) = log₂(2⁴) = 4 ✅
log₂(x) = 4 2⁴ = x x = 16
